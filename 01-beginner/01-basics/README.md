# 01-basics — Python Fundamentals

Master the building blocks of Python programming: data types, operators, and basic syntax.

## 📚 Topics Covered

### 1. Variables and Data Types
- **Integers (int)** — Whole numbers, arbitrary precision
- **Floats (float)** — Decimal numbers, floating-point arithmetic
- **Strings (str)** — Text, immutable sequences, Unicode
- **Booleans (bool)** — True/False values
- **Type checking and conversion** — `type()`, `isinstance()`, casting
- **None** — The null value in Python

### 2. Operators
- **Arithmetic** — `+`, `-`, `*`, `/`, `//`, `%`, `**`
- **Comparison** — `==`, `!=`, `<`, `>`, `<=`, `>=`
- **Logical** — `and`, `or`, `not`
- **Assignment** — `=`, `+=`, `-=`, `*=`, `/=`, etc.
- **Membership** — `in`, `not in` (for strings, lists, etc.)
- **Identity** — `is`, `is not` (comparing object identity)

### 3. String Manipulation
- **String indexing and slicing** — Accessing characters and substrings
- **String methods** — `.upper()`, `.lower()`, `.strip()`, `.split()`, `.join()`, `.replace()`, etc.
- **String formatting** — f-strings, `.format()`, `%` operator
- **String escaping** — `\n`, `\t`, `\\`, raw strings
- **String operations** — Concatenation, repetition, membership

### 4. Input/Output
- **`print()`** — Displaying output, multiple arguments, separator, end parameter
- **`input()`** — Receiving user input (always returns string)
- **Type conversion** — Converting input to appropriate types
- **Formatted output** — Using f-strings and `.format()`

### 5. Basic Python Concepts
- **Comments** — `#` for single-line, `"""` for docstrings
- **Variable naming conventions** — PEP 8 style (snake_case)
- **Reserved keywords** — Understanding Python keywords
- **Case sensitivity** — Python is case-sensitive
