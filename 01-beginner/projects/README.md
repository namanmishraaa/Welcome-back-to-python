# Beginner Projects

Apply your knowledge from basics, control flow, and functions with these three progressive projects.

## 📋 Project Overview

These projects integrate multiple concepts and build your confidence in writing complete programs.

### Project 1: Calculator 🧮
**Topics Used:** Basics (input/output, data types), Control Flow (conditionals), Functions

**Difficulty:** ⭐☆☆

**Description:**
Build a simple calculator that:
- Takes user input for two numbers and an operation
- Supports: addition, subtraction, multiplication, division
- Handles invalid input gracefully
- Continues until user quits

**Learning Goals:**
- Organize code with functions
- Handle user input validation
- Use conditionals for operation selection
- Understand program flow control

**Suggested Enhancements:**
- Add more operations (exponentiation, modulus, floor division)
- Support multiple operations in one calculation
- Add a history of calculations
- Convert to a GUI with tkinter

---

### Project 2: Number Guesser Game 🎯
**Topics Used:** Basics (random), Control Flow (loops, conditionals), Functions

**Difficulty:** ⭐⭐☆

**Description:**
Build a number guessing game where:
- Computer picks a random number (1-100)
- Player guesses, gets hints (too high/low)
- Game tracks number of attempts
- Player can play multiple rounds

**Learning Goals:**
- Use the `random` module
- Implement game loops with proper exit conditions
- Provide user feedback based on logic
- Keep track of game state

**Suggested Enhancements:**
- Difficulty levels (easy: 1-50, medium: 1-100, hard: 1-1000)
- Limited attempts mode
- Scoring system based on attempts
- Leaderboard (store results in file)

---

### Project 3: Todo List 📝
**Topics Used:** Basics (data structures), Control Flow (loops), Functions, File I/O

**Difficulty:** ⭐⭐☆

**Description:**
Build a simple todo list application:
- Add items to a list
- Mark items as complete
- Remove items
- Display the current list
- Save/load from a file (bonus)

**Learning Goals:**
- Work with lists effectively
- Organize code with functions
- Handle basic file I/O
- Build a simple CLI menu system
- Understand program state management

**Suggested Enhancements:**
- Save todos to a file (persistent storage)
- Load todos on startup
- Mark todos as complete without removing
- Filter by completed/incomplete
- Add due dates
- Categorize todos
- Search functionality

## 🏆 Project Completion Checklist

For each project, ensure you:
- ✅ Write clean, well-organized code with functions
- ✅ Add comments explaining your logic
- ✅ Handle edge cases and invalid input
- ✅ Test thoroughly with various inputs
- ✅ Refactor for readability
- ✅ Add docstrings to your functions

## 📚 How to Complete Projects

1. **Plan** — Understand requirements, design your approach
2. **Code** — Implement step by step, test as you go
3. **Test** — Try various inputs, look for edge cases
4. **Refactor** — Improve code clarity and organization
5. **Enhance** — Add one of the suggested enhancements

## 💡 Tips

- Start simple, add features incrementally
- Test each function independently
- Use meaningful variable names
- Don't over-complicate; simple solutions are often best
- Re-examine your code after completing it — can you improve it?

## 🚀 Next Steps

After completing beginner projects:
