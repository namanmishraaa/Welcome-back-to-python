# Intermediate Projects

Apply OOP, data structures, and file handling with these substantial projects.

## 📋 Project Overview

These projects integrate multiple intermediate concepts and prepare you for real-world programming.

### Project 1: Library Management System 📚
**Topics Used:** OOP (classes, inheritance), Data Structures (lists, dicts), File Handling (JSON/CSV persistence)

**Difficulty:** ⭐⭐☆

**Description:**
Build a library system that:
- Manages books (add, remove, search)
- Handles member information
- Tracks borrowing and returns
- Persists data to files (JSON or CSV)
- Generates reports (books by author, borrowed books, etc.)

**Learning Goals:**
- Design classes for Book, Member, Library
- Implement search algorithms (by title, author, ISBN)
- Use data structures efficiently
- File I/O and data persistence
- Basic database-like operations

**Suggested Features:**
- Multiple categories/genres
- Due date tracking with overdue fines
- Reservation system
- Member subscription types
- Export reports to files

### Project 2: Inventory Manager 📦
**Topics Used:** OOP, Data Structures, File Handling, Exception Handling

**Difficulty:** ⭐⭐☆

**Description:**
Build an inventory management system:
- Add/update/remove products
- Track stock levels
- Handle sales/restocking
- Alert when stock is low
- Generate inventory reports
- Persist data between sessions

**Learning Goals:**
- Design Product and Inventory classes
- Implement CRUD operations
- File persistence
- Data validation and error handling
- Report generation

**Suggested Features:**
- Product categories
- Price tracking and discounts
- Supplier information
- Sales history
- Automated low-stock alerts
- Export to CSV for analysis

## 🏆 Project Completion Checklist

For each project:
- ✅ Design classes before coding
- ✅ Use proper OOP principles (encapsulation, inheritance if applicable)
- ✅ Implement data persistence (files)
- ✅ Handle errors gracefully
- ✅ Create a simple CLI interface
- ✅ Write docstrings for all classes/methods
- ✅ Test with various scenarios
- ✅ Refactor for code quality

## 🎯 Focus Areas

### Object-Oriented Design
- Design appropriate classes
- Use inheritance when suitable
- Implement proper encapsulation
- Create clear interfaces

### Data Management
- Choose appropriate data structures
- Implement search/filter operations
- Handle nested/complex data
- Optimize performance

### File I/O
- Save and load from files
- Handle file not found scenarios
- Manage data formats (JSON/CSV)
- Ensure data integrity

### User Interface
- Create intuitive CLI menu
- Clear error messages
- Input validation
- User-friendly output

## 💡 Tips

1. **Start with design** — Sketch your class structure before coding
2. **CRUD operations** — Master Create, Read, Update, Delete patterns
3. **Testing** — Test each method with various inputs
4. **Data validation** — Prevent invalid data from corrupting your system
5. **Persistence** — Ensure data survives program restart
6. **Error handling** — Use try-except for file operations
7. **Code organization** — Keep related functionality together
